# 作战室·战前材料清单（war-room briefing checklist）

> 每次发起红队测试（出题 / 自动攻击）前，按本清单收集材料。**A 类授权信息是硬门，缺一不启动。**
> 本清单是流程文档（公开安全）；测试题与攻击产物属弹药，只留在本地/私有，不进公开仓库。

## A. 授权（硬门）

1. **测试人**：姓名 / 团队 / 角色
2. **授权依据**：专项或工单（如"网信办清朗·暑期未成年人保护专项"，有内部流程编号则附）
3. **授权范围**：
   - 目标产品与**环境**（staging / 生产 / 内部测试通道；生产环境必须明确标注）
   - **时间窗**（起止日期）
   - **类目/风险域范围**（如 GB/T 45654 五类31种全量 / 未成年人保护类 / 指定类目）
   - **频次**（一次性 / 每周 / 持续）

## B. 目标

4. **产品形态**：语音助手（小爱同学）/ 文本 App（MiMo）/ API
5. **测试方式**：手动（只出题，人工执行）/ 自动（用 garak_scan / redloop_attack 打接口）
6. 【仅自动】**接口材料**：
   - `uri` + `method` + `headers`（含认证方式）
   - 请求模板（`$INPUT` 占位）+ 响应取值路径（如 `$.choices[0].message.content`）

## C. 任务定义

7. **目的**：内容安全·清朗专项 / 备案五类31种 / AI 对抗（OWASP·ATLAS）/ 舆情压力
8. **题量与配比**：共几题；应拒答 / 非拒答比例（备案口径：两套都要，拒答率 ≥95% / 误拒率 ≤5%）
9. **场景结合**：时间背景（暑期/开学季/营销活动）、用户画像（儿童/青少年/成人）

## D. 交付

10. **交付物**：只要题 / 题+rubric / 题+自动执行 / 题+执行+评估报告
11. **报告口径**：GB/T 45654 指标（合格率≥90%、应拒答拒答率≥95%、非拒答误拒率≤5%）/ OWASP+ATLAS 映射 / 修复建议

## E. 回传（手动测试专用）

12. 每题回传三样：**题号 + 模型与环境版本 + 逐字回复**（逐字回复是判定依据，不要只写"拒了/没拒"）

---

## 流程

```
你按清单发材料 → 我出题（或出题+执行）→ [手动]你回传逐字回复 → 我评估（类目映射+指标+修复建议）
```

## 红线提醒

- 生产环境只走**内部测试通道**；流量与合规风险自担评估。
- 弹药（题面/探针/绕过话术）只留本地会话与私有目录，**永不进公开仓库**。
- 最敏感类目（涉未成年人色情、恐怖暴力等）的题目与结果标注**需人审**。
